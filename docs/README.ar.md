# TradeGuard Shield — ملخص عربي

## نبذة

TradeGuard Shield هو نظام مستقل لمعلومات المخاطر الخاصة بمواقع التداول. يجمع واجهة Fastify البرمجية، وإضافة للمتصفح، ولوحة تحكم، ونموذجاً مشتركاً للتقييم بلغة TypeScript بهدف عرض مؤشرات قابلة للتفسير قبل إيداع الأموال في منصة تداول.

هذا المشروع لا يصدر حكماً قانونياً أو مالياً أو تنظيمياً، ولا يثبت وقوع الاحتيال. النتيجة مؤشر للفرز والمراجعة، وليست ضماناً للسلامة أو توصية استثمارية.

## الحالة الحالية

الإصدار الحالي هو **v0.4.0**. تم تنفيذ واجهة API الأساسية، وخط التقييم، وإضافة المتصفح، ولوحة التحكم، وتكامل RDAP، وتغذية OpenPhish المؤقتة، والتكامل الاختياري مع Google Safe Browsing، وفحص TLS، ومهايئات PostgreSQL وRedis، وفحوصات CI. ما زالت معايرة العتبات، والتقييم المستقل، وتوسيع تغطية الجهات التنظيمية، والتحقق التشغيلي الكامل قيد العمل.

## المصادر والحدود

- RDAP: يستخرج تاريخ التسجيل ومؤشرات وسيط الخصوصية، مع اختلاف الحقول حسب نطاق المستوى الأعلى.
- OpenPhish: تغذية عامة مخزنة مؤقتاً لمدة لا تقل عن 15 دقيقة؛ غياب الموقع عنها لا يثبت الشرعية.
- Google Safe Browsing: اختياري ويتطلب مفتاحاً وحصة استخدام وشروط خدمة من Google.
- TLS: يتأثر بموقع الشبكة والأعطال المؤقتة.
- بيانات الجهات التنظيمية: تغطية محدودة وليست سجلاً عالمياً كاملاً.

تستخدم الاتصالات الخارجية مهلة قصوى قدرها ثلاث ثوانٍ، ويؤدي الفشل إلى نتيجة محايدة بدلاً من إسقاط الطلب أو اختلاق بيانات.
