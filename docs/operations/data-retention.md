# Data Retention

TradeGuard Shield should minimize personal data collection.

## MVP

- Check results are stored in memory.
- Reports are stored in memory.
- No production personal data retention is implemented.

## Production Requirement

- Define retention periods for reports, feedback, audit events, and evidence snapshots.
- Provide deletion and correction workflows.
- Avoid storing secrets, credentials, trading account data, seed phrases, or identity documents.
