# Legal And Ethics

TradeGuard Shield provides informational risk signals. It should avoid definitive statements such as "this website is fraud" unless that wording is supported by an official source and reviewed by counsel.

## Operator Requirements

- Keep evidence for every high-risk verdict.
- Provide a correction and appeal path for legitimate businesses.
- Avoid processing personal data unless necessary.
- Document retention windows for user reports and feedback.
- Separate financial advice from technical risk intelligence.
