# Contributing

Thank you for helping improve TradeGuard Shield.

## Development

```bash
pnpm install
pnpm typecheck
pnpm test
pnpm build
```

## Contribution Rules

- Keep risk claims evidence-backed.
- Add tests for scoring, URL validation, security, and signal-provider changes.
- Do not commit secrets, credentials, private keys, seed phrases, or personal financial data.
- Avoid language that states a website is fraudulent unless there is an official source and legal review.
- Prefer stable reason codes and documented scoring changes.

## Pull Requests

Pull requests should include:

- Summary of the change
- Risk or security impact
- Test results
- Documentation updates when behavior changes
