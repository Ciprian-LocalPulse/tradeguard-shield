# Support TradeGuard Shield

TradeGuard Shield is independent, self-funded, open-source research and engineering work on real-time risk intelligence for trading websites - an API, browser extension, dashboard, and explainable scoring engine designed to help users identify suspicious trading platforms before they deposit funds or share sensitive information.

Funding directly determines how much time can go into data-source integrations, risk-model design, browser-extension hardening, regulator registry connectors, threat-feed ingestion, privacy-preserving reporting, security testing, documentation, and eventually independent review of the scoring methodology.

## What Contributions Fund

Contributions directly support continued research and development of TradeGuard Shield, including:

- Development of the real-time trading-site check API
- Browser extension UX, badge accuracy, and permission minimization
- RDAP/WHOIS, TLS, Certificate Transparency, and threat-feed integrations
- Financial-regulator registry adapters for FCA, SEC, CySEC, ASIC, ESMA, FINRA, and related sources
- Explainable scoring rules, calibration, test datasets, and model evaluation
- User report and feedback workflows, including appeal and correction paths
- Security hardening, rate limiting, abuse prevention, logging, and auditability
- Docker, CI/CD, deployment automation, and developer tooling
- Documentation, wiki pages, governance, contribution guides, and roadmap maintenance
- Independent third-party security and methodology reviews as the project matures

## Funding Transparency

TradeGuard Shield is an independently developed research and engineering project. Financial support is intended to support the project's technical development along the path described in the roadmap:

**MVP API and extension -> Data-source integrations -> Analyst dashboard -> Pro alerts and watchlists -> Security review -> Public methodology audits**

Contributions do not purchase ownership of the project, control over the architecture or roadmap, preferential treatment, access to private forks or unreleased work, or influence over security decisions. The project's technical direction remains independent.
