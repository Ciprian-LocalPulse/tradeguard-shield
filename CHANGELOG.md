# Changelog

All notable changes to TradeGuard Shield will be documented in this file.

The format follows Keep a Changelog and the project uses Semantic Versioning.

## [0.1.0] - 2026-09-02

### Added

- Initial TypeScript monorepo with API, dashboard, extension, and shared scoring package.
- Professional documentation, wiki source, manifesto, support page, and Docker notes.
- Production-oriented repository foundation with config, logger, security, testing, collector, and worker packages.
- GitHub Actions for CI, security audit, CodeQL, dependency review, extension packaging, and manual releases.
