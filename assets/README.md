# Assets

Project assets are original repository assets for TradeGuard Shield.

## Branding

- `branding/logo.svg`: primary logo
- `branding/logo-dark.svg`: dark-background logo
- `branding/logo-light.svg`: light-background logo
- `branding/wordmark.svg`: documentation and README wordmark

## Extension Icons

The extension icons are generated from the same shield concept and stored under `assets/extension/`. They are referenced by the Manifest V3 extension and copied into the extension build.

## Diagrams

Mermaid source diagrams live under `assets/diagrams/`.
